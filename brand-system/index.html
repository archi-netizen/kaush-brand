03 · Typography
Gloock, Manrope, and क in Rozha One.

Gloock carries headlines. Manrope carries everything meant to be read quickly. Rozha One is for the mark's Devanagari context only, not yet extended to running text.

Gloock — Display
Just call Kaush.
Manrope — Body & UI

All body text, navigation, labels, buttons. Weights: 200 for eyebrows on dark, 300 for body, 500 for labels, 600 for CTAs, 700 for emphasis only. Never 800 in UI.

Rozha One — Mark context
क

Currently scoped to the logomark only. Not used in headlines, body copy, or UI at this time.
