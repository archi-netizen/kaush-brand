Neural Asset Archives · AWS Architecture

From Passive Storage
to Active Intelligence.

A serverless cloud pipeline designed to transition static archives into active intellectual resources. Only the Rekognition stage has actually been run against real assets so far, tested manually through the AWS console — the rest is documented as proposed architecture, not yet built.

Amazon S3 Object storage for high-resolution design assets (renders, site photos, material studies) Proposed
AWS Lambda Event-driven logic triggered on upload — serverless, no persistent infrastructure Proposed
Amazon Rekognition Computer vision: spatial hierarchies, material qualities, label detection Tested · Manual
Amazon Bedrock Private LLM instance to synthesize raw labels into design summaries and Basket classification Proposed

Processing Flow

01
UPLOAD → S3 Research-Archive
Design assets deposited in a private account. Zero exposure to public AI training loops. (Proposed.)
02
S3 EVENT → Lambda
Upload event triggers a serverless function. No persistent server costs or infrastructure overhead. (Proposed.)
03
REKOGNITION ANALYSIS
Computer vision extracts visual labels, material qualities, spatial hierarchies. Run manually via the AWS console against three test assets.
Architecture: 99.8% · Factory/Building: 99.8% · Person: 98.6%
04
BEDROCK SYNTHESIS
Intended to convert raw labels into design summaries and assign assets to AI-KORP Baskets. Not yet run against these assets. (Proposed.)
05
NEURAL ARCHIVE DATABASE
Final metadata stored as a searchable, tagged knowledge base — "the Granary." Designed, not yet built.

Extending to Urban Scale · Preprint, 2026

The Decorated Shed, at City Scale.

The building-scale test above extends to a survey of six German logistics facilities using publicly available aerial imagery. Visual examination — without classifier intervention — reveals three distinct ways brand and architecture fuse into a single visual layer, before any AI system touches the imagery.

Type Signal carrier Facilities
A — Fleet-carried A neutral envelope; brand signal carried entirely by trailers, trucks and branded loading equipment. DHL Osterweddingen · PENNY Cologne
B — Envelope-carried Colour and mark applied at architectural scale — readable from altitude without the fleet present. KiK Bönen · IKEA Dortmund
C — Hybrid Envelope and fleet carry the brand signal simultaneously, at every layer — the most complex case for any classifier. EDEKA Oberhausen · DHL Münster-Nord

In all three types, the fusion precedes the classifier — it exists in the built environment before any AI system touches the imagery. Left ungoverned, generative and classification AI systems inherit it without disclosure or verification. Full methodology, figures and the literature review are in the preprint.
