Technical Architecture

From Passive Storage
to Active Intelligence

A serverless AWS pipeline intended to move a practice's archive from static storage to an active, queryable resource. Of these stages, only Rekognition has actually been run against real assets so far — manually, through the console, not via an automated trigger.

Governance & Sovereignty

Responsible Architecture
by Design.

All research conducted with personal subscriptions and private hardware. No proprietary client data used. This framework does not claim "EU AI Act compliance" — a legal status only a qualified assessment can confer — its ambition is to stay aligned with the Act's literacy and disclosure logic.
